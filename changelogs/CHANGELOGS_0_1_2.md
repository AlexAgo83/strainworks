# Strainworks 0.1.2

Release date: 2026-11-23.

## The game

- The installed app offers a new version when one is published: during a game, a message asks to update,
  and the game is saved and reopened on the new version. Outside a game the update applies at once.
- A model lab at `?lab` shows every 3D model at every stage, beside its state.

## Fixes

- Installed on an iPhone home screen, the game takes the whole height of the screen.
- The 3D view no longer stops when the core reaches stage 4.
