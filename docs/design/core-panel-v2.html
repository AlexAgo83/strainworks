Le principe

  1. Une demande à la fois. Les onglets en haut passent de l'une à l'autre ; un point rouge marque celle qui bloque.
  2. La recette en schéma, avec les pictos du jeu, de haut en bas : les bases avec leur numéro d'entrée, la machine, ce qui en sort, jusqu'au cœur.
  3. Les réglages de machine sont écrits dessus (encapsuleur : capsule ou chargeur ; Ligase : gauche, derrière, droite).
  4. Contour vert : tu le produis déjà. Pointillé : il te manque. Rouge : ta machine est mal réglée, avec la phrase qui dit quoi faire.
  5. Rien d'autre : l'histoire, les gènes de base et ce que débloque le stade passent dans l'onglet du stade ou l'aide.
